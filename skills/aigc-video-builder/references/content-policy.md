# 从构建层面规避内容政策风险

目标：写出的场景既有完整的电影冲击力，又从一开始就*不需要*描绘任何违规内容。这是一种创作约束而非能力限制——下面的替换方案通常反而*更有*电影感。从源头把场景写安全，而不是写了危险内容再指望它能过审。

## 核心原则

不描绘伤害本身；描绘能量、余波、威胁感和规模感。对峙比屠杀更紧张，疏散一空的城市比恐慌的人群更瘆人，一声咆哮比一次击杀更有力量。

## 替换对照表

| 避免 | 改用 |
|---|---|
| 恐慌的平民、在废墟下逃窜的人群 | **已疏散**/空无一人的城市；废弃街道；只留一个孤独人影做比例参照 |
| 军用武器向建筑/人群开火 | **能量对峙**、探照灯扫射、蓄能光环、无枪口火焰的冲击波 |
| 生物互相撕咬/血腥场面 | **缠斗/对峙**、咆哮、险些命中、互相绕行、能量碰撞；战斗收束在"水面之内"或其他限定范围 |
| 有人处于危险中的破坏场面 | 破坏发生在**无人地带**——冰川、沙漠、遗迹、公海、已疏散区域 |
| 以写实枪械为画面焦点 | 风格化/奇幻化的器械；背着不开火的武器；武器只作为剪影/道具 |
| 血、伤口、死亡 | 撞击闪光、烟尘、碎屑、结构弯折坍塌、一个剪影跌出画外 |
| 真实存在的公众人物 | 原创/匿名角色 |
| 真实品牌 logo | 原创或泛化的品牌（用户自己的产品除外——那正是重点） |

## 已验证的安全基准

参考安全场景：**一只原创生物，在一个泛化的纪念碑/圆形剧场里，白天，画面中没有武器，做有表现力的动作（起身、咆哮、展开双翼）。** 一只生物、原创设计、泛化场景、日光、表现力而非暴力。当场景开始往危险方向漂移时，就往这个形状拉回来。

## 未成年人——硬性规则

绝不撰写涉及或指向未成年人的浪漫、性或暗示性内容，绝不写任何将年幼形象性化的内容。任何涉及儿童的场景保持健康、符合年龄。此条不容商量，优先级高于一切风格目标。

## 生物与战斗——保持收束

- 一到两只**原创**生物，明确声明 "not based on any franchise"。
- 给战斗一条**收束规则**，同时也锚定了物理："stays at the sea surface"（始终停在海面）、"never flies into the air"（绝不飞天）、"boss scale locked ~2.5 human-heights, not kaiju-giant"（boss 比例锁定约 2.5 人高，不是 kaiju 级）。这条既提升画面连贯性，又避免暴力升级。
- 偏好**表现力动作**（破土而起、咆哮、跃出水面、展开双翼、猛地把头转向主角），而非描绘受伤。

## 不伤人也能有史诗级利害感

安全地获得史诗感：渺小人影从*坍塌的地形*中扑身闪开（而不是被压住）、战争号角响彻*空旷*的原野、一支军队在冰封峡谷中*仓皇奔逃*而泰坦正从冰川中挣脱——危险来自环境，人物是在反应而非受害。雪浪、发光符文、崩裂的冰面承载全部混乱感。

## 交付前快速安检

交付任何涉及冲突、生物、人群、武器、破坏或年幼角色的 prompt 之前，确认：

- [ ] 没有描绘恐慌/受害的平民；人群已疏散或不存在。
- [ ] 没有武器向人/建筑开火；威胁通过能量/探照灯/剪影表达。
- [ ] 没有生物互伤或伤人的血腥场面；战斗是缠斗/对峙/咆哮，且有收束规则。
- [ ] 破坏发生在无人/已疏散地带。
- [ ] 生物是原创而非 IP；无真实公众人物；无真实品牌 logo（用户自己的产品除外）。
- [ ] 涉及未成年人的内容全部健康、符合年龄。

任何一项不通过，先套用替换对照表再动笔。
