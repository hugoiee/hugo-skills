# 风格配方

每份配方列出该风格的标志性配料。在 `structure.md` 的通用段落之上搭建。配方只是起点——目标是让用户能做出*任何东西*，可以自由组合与偏离。

prompt 正文中的英文关键词（如 8K photoreal、Lumen GI、chase-cam）请原样保留在英文 prompt 里——它们是视频模型认得的行话；括号内的中文只用于理解。

---

## 实拍电影感（史诗/剧情向）

**画面基调：** 8K photoreal（8K 照片级写实）、anamorphic widescreen（变形宽银幕）、35mm film quality（35mm 胶片质感）、细腻颗粒、专业调色、steadicam 般的流畅运镜。写实，明确 NOT 3D/game。
**摄影机：** 像"第二个飞行者"或地面存在一样环绕/追逐主体；whip-pan（甩镜）；撞击时刻加手持晃动。
**结构：** oner 和 multishot 都成立。史诗感需要压倒性的比例反差——渺小的人影对阵庞然巨物。
**招牌手法：** 一个"钩子"事件（第二只巨兽出现、一次险些相撞）触发一次慢动作节拍，然后猛地切回俯冲/追逐。
**生物：** 原创设计，用具体细节描述（兽皮、翅膀、生物荧光纹路），声明 "not based on any franchise"。
**灯光：** 冷色世界里的一抹暖色点缀（青灰风暴中的琥珀色生物荧光）效果极佳。
**音频：** 全部环境内真实音效；咆哮、风声、雷声；慢动作时环境音跌入闷响真空 + 心跳声，恢复常速时伴随音爆呼啸。

## 3D 动画长片（皮克斯品质，带对白）

**画面基调：** 鲜艳光泽的 CGI 渲染、Pixar-quality 风格化动画、次表面散射的毛发/皮肤、夸张的卡通表演、斑驳日光、浓郁饱和的配色、精湛的景深控制。
**结构：** multishot 蒙太奇——明确写 "Don't use one camera angle or single cut"（不要单机位单剪切）。6 镜 / 15 秒是验证过的黄金结构。
**角色：** 憨态可掬、表情夸张、设计具体（毛茸茸的橙色独角怪、圆滚滚的蓝色鳞片小龙、长满苔藓的树精）。前景蕨叶间藏一个小小的背景角色，既加景深又添喜剧感。
**对白：** 每个镜头可以带一句引号内的台词，并描述说话方式（"bursting with excitement he says:"、"whispers:"、"they all gasp:"）。台词要短、要有角色个性。
**逐镜头机位：** 刻意变化——push-in（推近）、close-up（特写）、wide（全景）、tracking（跟拍）、insert（插入镜头）、wide。每次都写明运镜。
**喜剧节拍：** 落一个视觉包袱（宝藏其实一直被踩在脚下），配一句讪讪的收尾台词。
**音频：** 这个风格可以用轻配乐，但优先遵循用户默认（通常仍以 SFX 为主）。

## 游戏引擎过场（第三人称，常驻 HUD）

**画面基调：** AAA video-game cinematic、Unreal Engine 5 real-time in-engine render（UE5 实时引擎内渲染）、Lumen GI、Nanite micro-geometry、screen-space reflections。超写实但一眼能看出是游戏渲染——明确写 NOT live-action、NOT film。皮肤是游戏角色的次表面质感，NOT 实拍毛孔。
**摄影机：** 虚拟游戏运镜、第三人称越肩视角、180° 快门运动模糊、游戏过场式景深。
**结构：** multishot 硬切，典型 3 镜 / 15 秒。默认 NO slow-mo；speed-ramp 只留给一两个大节拍。
**HUD LAYER——定义性特征。** 精确复刻参考 HUD：扁平 2D 屏幕空间 UI、锁定的点缀色 hex 值、每个镜头都钉死在屏幕上（不随摄影机移动/视差；数字可以跳动，布局锁死）。逐项枚举每个元素的精确文字和位置——罗盘条、小地图、任务日志（带任务名 + 进度计数）、等级/经验/血条/耐力条、快捷栏、弹药 + 货币、世界空间内的 `[E] PROMPT` 交互提示。boss 血条在亮相时刻淡入。
**主体：** `@handle` 玩家角色 100% 匹配引用，越肩取景，像一个可操作的主角。
**场景：** 引用图是总风格参考而非固定关键帧——世界向前延展，主体在空间中移动，不钉死在画面里。
**约束：** HUD 在每个镜头里都清晰一致，点缀色锁定；碎屑有接触阴影；生物比例锁定（例如 boss 变异体约 2.5 个人高，NOT kaiju 级巨物）；NO eye glow（禁止眼睛发光）。
**音频：** NO MUSIC，仅 SFX，外加细微的 UI 音效（路径点 ping、任务更新提示音）。

注：带 HUD 的游戏过场 oner 也成立（参考"水淹大教堂 boss"那个例子）——一个不间断的第三人称长镜头，HUD 全程烧在画面里，行内插 `[VFX: blade ignition]` 这类 VFX 标签。

## 游戏实机画面（街机风、锁定机位、实时 HUD）

**画面基调：** AAA 街机式实机画面（Forza Horizon / Need for Speed 那味）。高饱和、高光泽、高对比的实时引擎渲染，UI 锐利钉死。是游戏实机，NOT 电影素材。
**摄影机：** 经典第三人称追逐机位，稳如磐石，锁定在载具上；超广角；世界带重度速度模糊，主体锐利如刀。机位跟随漂移偏航但主体始终居中。无手持晃动，无破坏追逐感的剪切。
**结构：** multishot 但全程实机视角，3 镜 / 15 秒。全程 NO slow-motion——始终全速，极限动感。
**HUD：** 实时竞速 UI 钉在屏幕上，点缀色 hex——转速表、爬升的数字时速、挡位、充放的 BOOST 条、带危险标记的小地图、圈速计时器、名次。扁平贴在屏幕上，绝不出现在 3D 世界里。
**世界：** 所有元素的设计与引用保持一致；模型随主体深入把赛道向前延展。不加新角色/道具/配色。不用真实品牌 logo。
**音频：** NO MUSIC，仅 SFX——引擎轰鸣、换挡、氮气呼啸、轮胎尖叫、撞击闷响、UI 提示音。

## FPV / POV 一镜到底（单个连续镜头）

**画面基调：** single continuous shot、one take no cuts、电影级 FPV/POV oner、4K 超高细节、写实微距、anamorphic、流畅的无人机/穿越机飞行。
**摄影机：** 摄影机本身就是一个飞行/第一人称的存在。POV：干净的人眼视野，NO 头盔/面罩/HUD，画面底部露出骑手握着操控物的双手，带有机的微颤和反应式视线移动。FPV 穿越机：扎进烟尘云团、贴着表面掠过让每种材质都看得清、永不停顿、never pulls up or back（绝不拉起或后退）。
**结构：** 一整段不断开的文字，节拍用时间戳标注。唯一的速度变化必须点名：一次颠簸/打击触发慢动作或子弹时间微距节拍（如 240fps），然后猛地切回实时（24fps）。变速要写明 fps 数值。
**招牌手法：** 贴着表面的微距掠过；中段一个慢动作微距悬停；打击瞬间一个冻结的子弹时间环绕；慢速节拍上出现 anamorphic 镜头光晕。
**音频：** 环境内真实音效；慢动作时所有环境风声跌入闷响真空，被放大的节律声取代（翼拍声、心跳声），现实回归时伴随一记音爆呼啸。

## 产品/商业广告片

**画面基调：** 8K 照片级写实的 editorial 商业片，电影感、情绪化，深邃黑位压缩，逐角色/逐段落的独立色彩世界。
**结构：** multishot、大量短段落（8–10 段）、动作点上 HARD match-cut。通常只允许一个具名的风格化转场（一次 FILM BURN），其余全部硬切。以 HERO PACKSHOT（产品英雄定格镜头）收尾。
**段落编排：** 人与产品的互动镜头 + 快速微距产品蒙太奇（0.3 秒剪切、每切一刀带频闪）交错剪辑。每个角色拥有自己的色彩/光照世界。
**产品锁定：** 产品与引用图的摆放完全一致；logo 精确显示指定文字且保持锐利；产品颜色锁死（精华液保持绿色、面霜保持白色）。在 POSITIVE LOCKS 里重申。
**Packshot：** 产品占画面三分之一，其余是干净的暗色留白，缓慢 dolly-in，粒子飘浮（金尘），微弹跳落定，定格。
**摄影机：** crash-zoom、微距探针镜头、snap-rack focus、产品交互时 speed-ramp、packshot 上慢速 dolly。
**物理：** 液滴的表面张力、面霜带重量感地铺开、水珠凝结、尘埃受重力下落、正确的接触阴影。
**音频：** NO MUSIC、NO 旁白、NO 屏幕文字——只有产品操作的真实音效（玻璃轻碰、按压泵头的嘶声、喷雾声）+ 环境低频铺底；只在 film burn 上出现一次余烬嘶响。

多剪切 CGI 产品蒙太奇（如"10 个 3D CGI 产品剪切"）同理：每一刀都超细节展示产品表面/机械结构，全程硬切，干净收尾。

## 基于源视频的 VFX 合成（输入锁定）

**画面基调：** 8K 电影级、照片写实——明确 no 3D render、no game engine、no game-cutscene look。实体生物特效级写实：毛孔级的湿润半透明真皮、可见毛细血管、反光的黏液膜。构图和调色从 `<<<video_1>>>` 继承。
**核心规则——INPUT LOCK：** 源片全程原样保留。逐项列出画面里的一切（桌子、设备、灯光、人物、调色、手持运镜的精确构图/焦段/晃动/时机）。禁止重新调色、变速、平滑、重新构图。唯一的新增是：新元素 + 它投下的光 + 它的接触阴影 + 湿润的黏液膜 + 宿主物体的轻微物理反应。
**摄影机：** 精确继承源片摄影机。新增元素视差锁定（parallax-locked）在其锚定平面上从而正确跟踪；遮挡关系正确（肢体压在物体前、从边框后面钻出来）。
**主体：** 新增的生物/元素锚定在画面内某个真实物体上（例如从笔记本屏幕里钻出来——屏幕被当作一层会被撑开、随每条肢体产生表面张力水珠的液态膜）。
**约束：** 时长与源片完全一致；NO slow-motion（保持源片实时速度）；NO eye glow；无 CG/游戏感；比例锚定在画面内真实物体上以保证可信度。
**音频：** NO MUSIC，仅 SFX——新元素的真实音效叠在微弱保留的房间底噪之上。

## 怪兽/巨兽大片（原创设计）

**画面基调：** 8K photoreal、anamorphic、原创怪兽的大片级调色、细腻颗粒、超高细节。
**结构：** 剪切序列（常为 6 刀），可用 OPTICS 逐刀标注（每刀焦段 + 角度）。慢动作只给一个节拍（例如跃出水面那一刻）。运动从静止逐渐加速到暴烈搏斗。
**角色设计：** ORIGINAL，不基于任何 IP——具体描述兽皮、眼睛、鳍、触手、外套膜。
**连续性——关键：** 所有剪切里是同一只生物/同一只眼睛/同一个环境；CUT 1 开场那只闭着的眼睛，就是 CUT 2 里镜头推近的那只。明确写出来，并告诉模型不许弄丢。
**收束规则：** 把打斗限制在一个可信的范围内（战斗始终停留在海面——生物跃出、下潜、缠斗、没入，但绝不飞天、绝不被甩上天）。这条既锚定物理又避免离谱输出。
**摄影机：** 细节微距 → 急速硬推 → 广角跃出 → 手持镜头带水珠俯冲 → 海面缠斗 → 高空大全景。永不静止。
**物理：** 真实的质量与流体动力学——跃出时推开一整面水墙，下潜时水体向内塌陷，水珠挂在镜头上，触手甩动时带着阻力。
**音频：** 全部真实音效——海洋环境声、渐起的低鸣、眼睛猛睁的音效重音、水爆声、咆哮、次声波轰鸣。

陆地泰坦（冰/石巨人 + 军队）同一套 DNA——压倒性的太古比例、每次碎裂动作都带手持晃动、在泰坦与渺小士兵之间来回切以强调比例、发光符文作点缀色、漫天雪浪。破坏限制在无人/已疏散地带（见 content-policy.md）。

## 组合新风格

如果请求与上面都不匹配，直接从 `structure.md` 搭建：

1. 选定渲染基调，写明它是什么（以及不是什么）。
2. 选 oner 还是 multishot。
3. 确定摄影机语言和一个招牌动作。
4. 填满三层景深，放一个比例参照人物。
5. 锁定所有引用素材。
6. 加物理 + 实用光源 + 音频。
7. 跑一遍交付前自检清单。

段落词汇表与风格无关——它能承载任何类型。
