# 内容工具箱（双人版）：类比 · 数字 · 口头禅双系 · 句子规则 · 可信度

> Step 5（逐块台词）与 Step 6（口语化 pass）参考。内容技巧与单人方法论同源，此处标注双人分工。

## 一、类比系统（归 B 投出，A 接住）

### 三条铁律
1. **永远向下找参照物**：从不用行话解释行话。语料库六个：厨房饭桌、街坊家庭、校园游戏、身体、动物、童年记忆。
2. **好类比是结构件**：核心类比反复回收贯穿全篇；双人格式的回收可以由 A 完成（"这不就是你刚才说的那个温水煮青蛙吗？"）——A 主动调用 B 的类比 = 观众学会的时刻。
3. **给官方术语起揭底的新名字**："moon shot plan → 应该就叫投票权白送计划"。双人版可以让 A 起名、B 拍板，或 B 起名、A 惊呼——命名瞬间做成小高潮。

### 类比范例库（学思路不抄句子）
| 抽象概念 | 类比 |
|---|---|
| 央行放水控制不了流向 | 灌溉系统：只能开水阀，水流进稻田还是蓄水湖管不了 |
| 兜底机制的道德风险 | 扔硬币但亏损封顶100万 → 你会去赌一个亿 |
| 借股票做空 | "李哥呀，你这股票能不能借给我？" |
| 热钱 | 热锅上的蚂蚁一样的钱，到处乱窜 |
| 稳定性 vs 刺激性政策 | 信用卡展期 vs 银行帮你找工作 |
| 巨头互投的系统性风险 | 火烧赤壁：大船小船绑一起，怕火 |
| 政府型企业 | 巨大的房地产开发商 |

双人加成：类比可以现场"测试"——B 抛类比后 A 用它反推（"那按这个说法，股市就是那个蓄水湖？"），推对了类比成立，推歪了 B 再修——观众跟着 A 完成理解闭环。

## 二、数字六法（B 投球，A 接球）

| 法 | B 的动作 | A 的动作 |
|---|---|---|
| 对比锚定 | 先铺锚再砸异常值："苹果10倍、特斯拉15倍、英伟达25倍——SpaceX，接近100倍" | 接惊讶＋确认："100倍？！美股就没有比它高的了吧？" |
| 换算成体感 | 给原始数字 | **换算归 A**："我算算……那做空俩礼拜就亏一半？" |
| 阶梯念数 | "两百、三百、五百、八百……一千" | 中途插情绪："别涨了别涨了" |
| 身体化 | "空头一年亏了四百亿" | "这些基金经理得掉多少头发啊" |
| 精确数字当证据 | 念精确数（"3亿零207万2285股"） | 发现规律的人是 A："等等，一加正好是13亿？！" |
| 单字放大 | "德国五年累计增长是——" | A/B 都可收："零。" |

原则：**揭晓的爽感尽量让给 A**——A 算出来、A 发现规律、A 恍然大悟，观众才有代入感。

## 三、口头禅双系分表

| | B（爆料系） | A（质疑系） |
|---|---|---|
| 开启 | 我跟你说 / 你想啊 / 注意哈 | 等会儿 / 不是…… / 我问你个事 |
| 转折 | 但有意思的来了 / 结果 / 别急 | 那不对啊 / 可我听说…… |
| 揭晓/确认 | 哎，问到点上了 / 没错 / 就是这句话 | 啊？？ / 好家伙 / 那也就是说……？ |
| 软化 | 哈（"注意哈"）/ 这是我猜的 | 我可能理解得糙哈 |
| 情绪重音 | What?!（转述荒诞信息时） | 好家伙 / 离谱 |

红线：两人不共用口头禅；每人每分钟填充词（呃/嗯/那个）≤2 个。

## 四、句子层面规则

1. 口播断句 8-18 字；B 单行 ≤60 字，超了拆行或改成被 A 打断。
2. 长铺短砸：B 长句蓄力，短句钉结论（"就这么简单，零。"）；A 的短句负责砸情绪。
3. 金句每块只留一句，独立成行（能截出来发弹幕）；B 出金句或 A 出恍然大悟句。
4. 对仗回环造金句："来得快，跑得更快""预制不是原罪，隐瞒才是"。
5. 复读强调改成双人版：B 说一遍，A 复述一遍（复述即第二次曝光）。
6. 中英夹带当节奏重音：术语配英文（B），感叹用英文（What?!）。
7. 允许口语碎片、自我修正、抢话——这些是临场感的来源，别改"干净"。

## 五、书面语黑名单（Step 6 清零）

综上所述 / 值得注意的是 / 首先…其次…再次 / 由此可见 / 不难发现 / 与此同时 / 众所周知 / 总而言之 / 基于以上分析 —— 全部替换成口语等价物（"你看""所以说白了""还有个事儿""这么一看"）。

数字口语化：35% → "三成多"；6000亿按读法"六千亿"计3字估时长。

## 六、人设与可信度动作（双人分配）

| 动作 | 单人版 | 双人版分配 |
|---|---|---|
| 资历背书 | "我之前在华尔街工作" | **A 替 B 说**："你不是干过这行吗"——他人背书更可信 |
| 苦功证据 | "我翻到第176页" | B 说苦功，A 拆台见证："你不会真看完了吧？" |
| 敢说不知道 | "老实讲我也不清楚" | B 坦白，A 追问确认——坦白瞬间反而立信 |
| 主动纠偏 | "注意，我不是这个意思" | 可由 A 先误读，B 纠偏——把纠偏做成一次交锋 |
| 敢下判断 | "要我说……" | B 下判断，A 可以不完全同意（"这个我保留意见"）——分歧本身是内容 |
| 敏感话题收敛 | 少开玩笑、看事看逻辑 | **两人同时收**：A 停止调侃，B 放慢——氛围切换比单人更明显，是很好的情绪路标 |

## 七、情绪曲线（双人版）

标准走势不变：好奇 → 赞叹先行 → 幽默/讽刺加码 → 震惊爆点（倒数第二块）→ 沉重纵深 → 温和落地。

双人加成：
- "先赞后损"可以拆给两人：B 负责赞（专业公允），A 负责损（观众情绪）——比一人自转更自然。
- 爆点的"震惊"由 A 承担（A 的反应=观众的反应指导）；B 保持冷静反而放大冲击。
- 转折词分工：B 用"结果/但有意思的来了"，A 用"那不对啊/等会儿"。
