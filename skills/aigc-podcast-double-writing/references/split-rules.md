# 声部拆分规则 · A的四种武器 · 开场双人化 · 结构速查

> 本文件是"单人爆款技巧 → 双人声部"的核心映射参考。范例中的单人原句出自头部财经科普博主爆款文字稿。

## 一、逐项映射表：单人技巧 → 双人拆分

| 单人稿里的技巧 | 单人原句示例 | 双人拆分后 |
|---|---|---|
| 自问自答 | "那利润发动机是什么呢？就是星链。" | A："那利润发动机是啥？" B："星链。" |
| 替观众提问 | "你可能要问了……哎，问到顶儿上了哈" | A 直接问出来；B："哎，问到顶儿上了。" |
| 预设答案再推翻 | "很多朋友想当然觉得靠石油——我跟你说，那你就草率了" | A："这不送分题嘛，靠石油呗。" B："那你就草率了——石油只占1%。" |
| 让观众抢答 | "我估计你猜都能猜出来了，就是AI" | B："你猜？" A："……AI？" B："对喽。" |
| 揭晓信号词"哎，对了/没错" | "和什么呢？哎，对了，无限的损失" | 变成 A 答对后 B 的确认，或 B 揭晓前 A 的催促 |
| 虚拟对白（替机构配台词） | "谷歌：亲儿子Gemini，不好意思了……" | 两人分饰：A 演一方 B 演另一方，真实交锋 |
| "哎别急/但你等一下"（侦探式转折） | "哎，别急，同学们，我们把课本翻回第235页" | A 急着要答案，B 压住："别急，你先看这个。" |
| 容错式安抚 | "这块逻辑万一没跟上，没事哈，之后如出一辙" | A 主动说"等等我有点晕"，B 用类比重讲一遍——A 替观众暴露困惑 |
| 当场算账 | "你这么一算，把我送上近地轨道也就不到五千美元" | 算账动作整体划给 A："等下我算算……那把我送上天才五千块？" |
| 打破第四面墙 | "哎呀累死我了哈！你是不是满脑子都是知识了？" | 变成两人互相吐槽："你这信息量也太大了，我先缓缓。" |
| 战略性省略埋钩 | "今天就不细说了哈，咱不能一口气吃成个胖子" | A 追问支线，B 拒绝并埋钩："这个展开又是一期，想听的评论区说。" |
| 苦功背书 | "我特意翻到招股书第176页" | 由 A 见证/拆台更可信：A"你不会真把几百页招股书看完了吧？" B"看完了，而且第176页有个东西你绝对想不到。" |
| 资历前置 | "这个话题我还是有点发言权的，之前在华尔街工作" | 由 A 替 B 说："你之前不就是干这个的吗？"——他人背书 > 自我背书 |

**拆分总原则**：凡是单人稿里"模拟双向交流"的动作（问、抢答、安抚、催促、质疑），全部划给 A；凡是"输出与揭晓"的动作（答、爆料、类比、数字、盖章术语），全部留给 B。

## 二、A 的四种武器（每块台词至少用一种）

1. **带错误猜测的问**：A 说出大众的想当然，等着被纠正。被纠正的瞬间对话就活了。
   > A："预制菜嘛，不就是料理包？" B："那你就把这个行业看小了——按国标，你说的料理包有一半根本不算预制菜。"
2. **当场算账**：把 B 的数字换算成体感，帮观众消化。
   > B："市场规模五千亿。" A："五千亿……全国摊下来，那我一年也交了三百多？" B："对，骂它的每个人都在交。"
3. **咬住具体词的追问**：必须引用 B 上一句里的具体词，往深挖一层。
   > B："行权价是0.01美元一股。" A："等等，一分钱？一分钱一股？那不就是白送？" B："哎，问到点上了。"
4. **复述确认（恍然大悟句）**：用自己的话把 B 的机制说一遍，说对了就是观众的记忆点，说得略偏还能让 B 再修一刀。
   > A："所以说白了，骂的人和买的人是同一批，因为他们骂的和买的根本不是一个东西？" B："就是这句话。"

红线：A 的每一行必须有信息增量（观点/换算/质疑/复述）。"哦这样啊""真的假的"连续出现两次 = 人形捧哏，重写。

## 三、开场60秒四变体（双人化范例）

开场三件事不变：分量证明、观看承诺、悬念挂起。

### 变体一：反常识炸弹型（概念/符号类）
```
B：迪拜，全球富豪移居最多的城市。你猜它怎么起来的？
A：这不送分题嘛，中东土豪，靠石油呗。
B：我跟你说，那你就草率了。迪拜的石油，只占GDP的1%。
A：1%？！那它那些楼是拿什么堆出来的？
B：这就是咱今天要聊的。而且我先说，它光鲜的背面还有些它不希望你看到的东西，这个咱们留到后面。
```
要点：A 的"想当然"必须是大众版本；B 推翻后 A 立刻用惊讶+追问放大反差；B 顺势挂大悬念。

### 变体二：惊人事实+连环设问型（连环事件类）
```
B：短短四年，墨西哥、东南亚、韩国、俄罗斯、巴西，数十个国家接连金融危机。
A：等等，这些国家隔着半个地球，怎么会一起崩？总不能都是索罗斯干的吧？
B：你问到点上了。而且我跟你说个更想不到的——这里边还有日本的银行什么事。
A：日本？日本银行招谁惹谁了？
B：别急。这背后有一条统一的主线，咱们今天把它串成一串——金融危机串串烧。
```
要点：原单人开头的五连问拆给 A；反直觉的那一问（日本）由 B 主动抛、A 接惊讶。

### 变体三：案件冷开场型（灰色题材类）
```
B：2023年8月15日晚上，四百多个新加坡警察，同时突击九处顶级豪宅。有个人从二楼阳台跳下去，脚腕都摔伤了，一瘸一拐躲进下水道。
A：好家伙，这是拍电影呢？抓着了吗？
B：抓着了。搜出来的豪车、名表、现金，加起来超过十亿美元。
A：十亿？！这钱怎么来的？怎么洗白的？
B：这个咱们一会儿再聊。我先问你个事——你知道全球每年洗掉多少钱吗？
```
要点：B 讲案件讲一半刹车；A 的催促（"现在就说！"）被 B 压住——挂起动作本身成为一次交锋。

### 变体四：定位差异化型（盘点综述类）
```
A：又到年底了，全网都在盘点。说实话我都看麻了，不是流水账就是一堆表格。
B：所以咱今天换个搞法：不按月份捋大事，也不挨个念数据，就抓一条主线——今年全球的关键词，就俩字。
A：哪俩字？
B：转向。听完你就知道，今年所有国家干的事，其实是同一件事的不同版本。
```
要点：A 替观众吐槽同类内容（树假想敌），B 给出差异化承诺——原单人开头的"自树自夸"变成一捧一诺，不油腻。

## 四、结构五模板速查（双人格式要点）

通用骨架：钩子 → 扫盲（A 主动要求："你先给我扫个盲"）→ 机制深挖 → 转折/阴暗面 → 统摄模型 → 升华 → 收尾。

| 模板 | 适用 | 双人化要点 |
|---|---|---|
| 洋葱式 | 概念扫盲 | 每层深挖由 A 触发（"这就完了？我不信就这么简单"）；"进度条钩子"改成 B 说"一般人讲到这就完了，咱们才刚开始" |
| 连续剧式 | 连环事件 | 口令句可以变成两人的接头暗号（B："然后呢？" A："我知道——资本又要开始流动了？" B："学会了啊"）；每场收尾 A 以为完了、B 说"还没完" |
| 光暗交替式 | 符号解剖 | 光面 B 讲得眉飞色舞，暗面转折由 A 引入（"但我听说……"）——两人各持一面天然成结构 |
| 案件三明治 | 灰色题材 | 开头案件 B 讲一半；结尾回看时让 A 用学到的知识自己破案（"等等，我现在会了——他是不是用了XX？"），A 的成长曲线=观众的成长曲线 |
| 总纲变量式 | 盘点综述 | 每个对象讲完 A 负责"归位"（"所以日本是反着转向的那个？"）；结尾总寓言两人一人一句拼出来 |

大悬念位置：放在**倒数第二块**（≈70%），不放最后一秒——观众注意力撑不到片尾，但压轴前还在。

## 五、双人人设卡模板

```
A（代观众 · 质疑系）
- 句长：短，8-15字为主
- 口头禅池（选3）：等会儿 / 不是…… / 啊？怎么还能…… / 我算算 / 好家伙 / 那也就是说……？
- 态度：好奇但不好糊弄；敢猜、敢错、敢算账；替观众暴露困惑

B（输出者 · 爆料系）
- 句长：中，但单行≤60字，常被A打断
- 口头禅池（选3）：我跟你说 / 你想啊 / 注意哈 / 哎，问到点上了 / 那你就草率了 / 别急
- 态度：懂行但不端着；先赞后损；敢下判断也敢说"这个我也不清楚"
```

台词比例 A:B ≈ 1:2。自检：遮住说话人名读三行，分不清谁在说 = 人设卡没贴住，重写。
