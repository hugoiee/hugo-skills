> Step 5（正文填充）和 Step 6（口语化 pass）的完整参考。

## 一、口头禅功能表

口头禅不是随意的，每个有固定功能。改稿时按功能植入，不是均匀撒：

| 口头禅 | 功能 | 用法示例 |
|---|---|---|
| "哈" | 软化断言、确认共识（最高频，每段可有） | "注意哈""你看哈""不过哈" |
| "哎 / 诶" | 转折与揭晓信号 | "哎，对了，无限的损失""哎，索罗斯来了" |
| "我跟你说" | 私下爆料感，抛反常识信息前必用 | "我跟你说，那你就草率了" |
| "你想啊 / 你想想" | 邀请观众一起推理，让观众自己推出结论 | "你想啊，这个垄断性越强……" |
| "你看 / 你看看" | 口语版"综上所述"，阶段性收束 | "你看，这不就稳了吗？" |
| "好" | 章节换挡离合器 | "好，我们说回美联储啊" |
| "对吧 / 是吧" | 寻求默契的尾缀 | "这很公平合理是吧" |
| "What?! / Wow / 好家伙" | 情绪重音（遇到荒诞信息时） | "竟然还有股东。What？" |
| "别急 / 你等一下" | 暂停-回放-放大细节（侦探式转折） | "哎，别急，同学们，我们把课本翻回第235页" |

用量红线：语气词服务节奏，过量比没有更假。终检靠朗读。

## 二、五个独门技巧

1. **昵称系统**：所有大佬去神化起中文外号——Carson Block="卡哥"、Bill Ackman="阿哥"、Carl Icahn="老坎"、FOMC="十二罗汉"、巴菲特="老爷子"。效果：华尔街叙事变成村口人物志。
2. **虚拟对白**：替机构/国家配台词，把谈判桌变情景剧——"谷歌：亲儿子Gemini，不好意思了，我去跟Anthropic抱在一起了""各国央行：美联储，您量大，您先降"。
3. **自我IP植入教学素材**：虚构案例用自己的名字（"小林奶茶店"）；拿自己当反面参照（"一个CEO是马斯克，一个是小林，那能一样吗？"）。
4. **打破第四面墙**：暴露创作过程当彩蛋——"哎呀，累死我了哈！你现在是不是满脑子都是知识了？""你就说咱这个收尾呼应巧不巧妙""好，这又扯远了哈，咱刚才聊什么呢？"
5. **方言与国民梗**：口语底色（东北味"蛄蛹蛄蛹""出溜"）+ 国民共识梗（大象装冰箱、天王盖地虎、"让通胀来得更猛烈些吧"）。梗要用观众的共同记忆，不用圈内梗。

## 三、术语处理三段式

**白话场景 → 命名 → 术语盖章**

> 先讲完整的"跟邻居老李借股票"故事，最后才盖章："这个就是做空 Short selling。"

- 顺序不能反：先给术语再解释 = 讲课；先给场景最后命名 = 揭晓。
- 偶尔补一句专业版并明示："咱稍微说专业点哈，就叫资本账户的盈余填补了经常账户的赤字"——展示"说人话是选择，不是水平"。
- 简化时保留严谨性标注："你可以**简单理解成**债务违约了"——既降维又免责。

## 四、数字六法

数字从不裸奔，必配参照物或换算：

1. **对比锚定**：先铺三个锚再砸异常值——"市销率苹果是10倍，特斯拉15倍，英伟达25倍，而SpaceX空降就接近100倍，美股最高。"
2. **换算成体感**："利率1500%是什么概念？就算市场完全不动，你做空两个礼拜就得亏掉一半的钱，这还没算杠杆。"
3. **阶梯念数**：逐级念出模拟加速——"股价从两百、三百、五百、八百，最后直接涨到一千。"日期+跌幅可排成"阵亡名单"。
4. **身体化/账单化**："空头一共亏了四百亿美金——你想想这些基金经理到底掉了多少吨头发？""每年少付1500亿——相当于从银行嘴里把钱抠出来。"
5. **精确数字当侦探证据**：精确到个位的念白本身就是揭秘爽点——"13亿零207万2285股……太空版给了10亿股，AI版给了3亿零207万2285股。哎，一加是多少？"
6. **单字停顿放大**："德国GDP累计的实际增长是——零。"

补充：教学时可先用极端数字（"10万的画鉴定成1000万"），再主动校准真实值（"现实中50万开100万发票更真实一些"）——夸张便于理解，校准维持严谨。

## 五、类比系统

### 三条铁律
1. **永远向下找参照物**：从不用行话解释行话。语料库只有六个——厨房饭桌、街坊家庭、校园游戏、身体、动物、童年记忆。
2. **好类比是结构件**：核心类比要反复回收贯穿全篇（"温水煮青蛙"首尾呼应、"脱发"梗出现5次以上、"小坏蛋被他妈查账"承担全篇教学框架），不是一次性装饰。
3. **给官方术语起揭底的新名字**：类比本身就是观点输出——"moon shot plan → 极限挑战 → 应该就叫**投票权白送计划**"。

### 类比范例库（学思路，不抄句子）

| 抽象概念 | 类比 |
|---|---|
| 央行放水控制不了流向 | 灌溉系统：只能开水阀，水流进稻田还是蓄水湖管不了 |
| 兜底机制的道德风险 | 扔硬币游戏但亏损封顶100万 → 你会去赌一个亿 |
| 借股票做空 | "哎，李哥呀，你这股票能不能借给我？" |
| 热钱 | 像热锅上的蚂蚁一样的钱，每天到处乱窜 |
| 稳定性政策 vs 刺激性政策 | 信用卡展期 vs 银行帮你找工作 |
| 财政扩张 + 央行加息 | 一边油门踩到底，一边拉着手刹 |
| 巨头互投的系统性风险 | 火烧赤壁：大船小船绑一起，怕什么？火！ |
| 资本圈派系 | 一张牌桌：老钱、天才创业者、鼎盛中年大佬、野路子 |
| 金融自由化的边界 | 不能让野孩子上大马路随便跑还美其名曰自由生长 |
| 政府型企业 | 巨大的房地产开发商：酋长是董事长，外来劳工是外包团队 |

## 六、句子层面规则

1. **短句主导**：口播断句8-18字，几乎不写30字不换气的句子。
2. **长铺短砸**：长句蓄力铺条件，超短句钉结论——"十五年内它不收任何的公司税跟收入税——就这么简单，零。"
3. **签名式重复**："最最最最重要""非常非常非常重要"。
4. **整句复读当强调**（口播原样念两遍）："要大力提振消费。要大力提振消费。"
5. **对仗回环造金句**："市场觉得你行你就行，不行也行；觉得你不行你就不行，行也不行""来得快，跑得更快"。
6. **排比 + 自我吐槽**："结构性能源短缺、结构性劳动力短缺……你什么都结构性，对吧。"
7. **单字成句**："零。""火！""乱！""绕吧。"
8. **中英夹带当节奏重音**：术语配英文（做空 Short selling），感叹用英文（What?!）。
9. **口语碎片化**：保留结巴式停顿模拟真人——"哎，你来，你，你不是缺算力吗？"

## 七、书面语黑名单（Step 6 清零）

综上所述 / 值得注意的是 / 首先…其次…再次 / 由此可见 / 不难发现 / 与此同时 / 众所周知 / 总而言之 / 基于以上分析 —— 全部替换成口语等价物（"你看" "所以说白了" "还有一个事儿" "这么一看"）。

## 八、人设与可信度动作清单

1. **资历前置**（开头60秒内）："这个话题我还是有点发言权的，毕竟之前在XX工作。"
2. **苦功证据具体化**：具体到页码、具体到动作——"好不容易在招股书第176页找到解释""我还特意根据财报算了一下这十年的数据""为了这期我看了上百个案例"。
3. **敢说不知道**："具体原因老实讲我也不是特别清楚，八成是……"——坦白换信任。
4. **主动纠偏防误读**："你可别觉得XX不行了哈，怕引起误解""注意，我不是这个意思。"
5. **敢下个人判断并署名**："要我说，最大的潜在危机就是……""就小林经常说哈……"（把"我经常说"做成句式）。
6. **知识宇宙互链**："这个咱们之前那期详细聊过"——暗示体系 + 导流。
7. **保留不完美**：口误花絮、自嘲（"我要是不说，你们可能也没发现"）。
