# 开场 · 收尾 · 广告植入（逐句公式与原文范例）

> 范例均出自头部财经科普博主的爆款文字稿原文。学的是排布公式，不是抄句子。

## 一、四种开场变体

开场必须完成三件事：**① 话题分量证明 ② 观看承诺 ③ 悬念挂起**。缺一件，开头就漏气。

### 变体一：极端后果排比 + 反常识炸弹（概念扫盲型）

> "政策出点问题，就导致了二十世纪最严重的全球经济大萧条。一次性就带来了美国股市十多年的大牛市。稍微监管不严呢，又招来了多次的金融海啸。这十二个人开开会动动嘴皮子决策就能影响全球经济。而就是这么重要的机构，它竟然还有股东，每年还会分红。What？"——《美联储》

逐句公式：
1. 极端后果排比（用历史极端事件堆权力感/分量感）
2. 权力具象化到"人"（抽象机构 → 12个具体的人 → "开开会动动嘴皮子"）
3. 反常识炸弹 + 英文语气词做情绪标点（"竟然还有股东。What？"）
4. 立刻亮资历（"小林还是有点发言权的，毕竟之前在华尔街工作"）
5. 内容菜单（"今天不光聊X，也想聊Y，还有我的一些小思考"）

### 变体二：惊人事实 + 连环设问（连环事件型）

> "一九九四年底到一九九八年，短短的四年间，墨西哥、东南亚、韩国、俄罗斯、巴西数十个国家接连出现金融危机……你说这都是索罗斯的阴谋吗？为什么这么多离着这么远的国家会相继崩盘？这里边有日本的银行什么事？小林为什么要把这么多危机放在一起讲？还能讲清楚吗？"——《金融危机》

逐句公式：
1. 极端数字冷开场，无寒暄（"短短四年""数十个国家"把规模密度打满）
2. 反差升级（"十多年奇迹在一年之内崩盘"）
3. 五连问埋悬念地图——其中必须有一个**反直觉问题**（观众预期主角是索罗斯，偏埋一个"日本的银行"）和一个**自我挑战问题**（"还能讲清楚吗？"）
4. 方法论承诺（"这背后有一条统一的脉络主线"——卖秩序感）
5. 命名打包 + 起跑（"金融危机串串烧""废话少说，我们开始"）

### 变体三：奇观堆叠 + 当场推翻常识答案（符号解剖型）

> "警察开着顶级超跑……两万美元一晚的总统套房，体验一把什么叫做睡觉睡到破产……人家炫富都不是炫给你看的，是炫给外星人看的……你说它是怎么从一个偏远的沙漠城市变成现在全球最光鲜亮丽的城市之一？可能很多朋友想当然就会觉得，这不送分题嘛，人家是中东土豪，那肯定是靠石油。我跟你说，那你就草率了。其实迪拜的石油很少很少，现在只能占到它GDP的1%。"——《迪拜》

逐句公式：
1. 亲历感官冲击（"我一下飞机就感觉到了另一个星球，五十多度"）
2. 奇观清单轰炸（连续5-6个"最"或反常识组合：沙漠+滑雪、睡觉+破产）
3. 一个权威数字锚点
4. 抛主问题
5. **预设观众的想当然答案，当场推翻**（"这不送分题嘛……那你就草率了"）
6. 预告阴暗面（埋全片最大悬念："大量被压榨的外来劳工……洗钱者的温床"）

### 变体四：案件冷开场 + 悬念劈两半（灰色题材型）

> "2023年8月15日晚，超过四百名的新加坡警察，同时突击搜查了九个新加坡顶级高档住宅。其中一名惊慌的嫌疑人从二楼阳台直接跳下来，手腕脚腕全都扭伤了，一瘸一拐躲到下水道里……总计价值超过十亿美元……这个案子具体怎么回事，这钱怎么洗的，我们一会再聊。"——《洗钱》

逐句公式：
1. 精确时间地点的电影级冷开场（数字先行：四百名/九个）
2. 动作细节具象到"脚腕"（画面感）
3. 战利品清单 + 金额锚点
4. 留未解之谜（"十七人至今在逃"）
5. **把案件劈成两半**："我们一会再聊"——答案压到全片80%处，结尾用全篇知识回看案件
6. 升维扩题 + 与观众关联（"哪怕普通的存钱转账，都可能暗藏洗钱"）+ 苦功背书（"我看了上百个案例"）+ 免责声明

### 特殊：盘点综述型开场 = 定位差异化

年度盘点/全景类不需要说服观众"这事重要"，要说服的是"看你这版而不是别人那版"：

> "很多人可能会给你捋一遍每个月发生了什么大事儿……听完热血沸腾，但是可能缺少一些重点或者逻辑。也有一些比较专业的分析，一个表一个表给你挨个分析数据，这个吧，确实是容易犯困。我是想尽量找到一个中间态……同时尽量说人话。"——《2024全球经济》

公式：树两个假想敌（流水账型、学院派型）→ 给自己定位中间态 → 自夸后立刻自嘲消油腻（"是不是感觉含金量还挺高的，反正我是努力过了，废话少说，咱们开始"）。

## 二、结尾四式

### 式一：口诀总结（压缩成可转发的记忆包）
> "每个国家基本上都是海外热钱大量涌入让你飘，然后热钱撤离，再加上空头趁火打劫——一进一飘一撤。"——《金融危机》
> "简单来说，就是同级之间竞争，不同级之间捆绑。"——《AI资本混战》

### 式二：发明概念词（让观众带走一个词）
> "马斯克通过多年成功的商业履历带来的信任，转化成了非常高的**马斯克溢价**。"——《SpaceX》

### 式三：开放提问导评论区
> "我也真的好奇哈，大家觉得三年以后的SpaceX会变成一个什么样的公司呢？又撑不撑得起它这么高的市值呢？"——《SpaceX》

要点：问题带时间跨度（利于长尾讨论）；两头都说、不下死结论（"仁者见仁智者见智"）。

### 式四：仪式闭环
- 首尾呼应且自己点破："哎，你就说咱这个收尾呼应巧不巧妙。"——《金融危机》
- 年度之约："朋友们，我们2025年再见。"——《2024全球经济》
- 宠粉："你能看到这儿哈，我觉得你真是挺棒的。"——《美联储》
- NG彩蛋：正片后保留口误花絮（"资本反击"念成"资本母鸡"）。

互动索取用人情逻辑："小林今天聊得也够意思了，我感觉你应该也听过瘾了，你不给个一键三连好意思吗？"

## 三、广告植入模板

- **位置**：全文35%-40%处，选一个故事闭环刚完成的"情绪安全点"。
- **进广告**：话题嫁接——用正文核心概念做桥：

> "资本的流动就是这么的快速高效，**但人就不一样了**，从一个国家到另一个国家，就会有网络、签证等等各种卡住。哎，别急，XX eSIM 就可以轻松帮你解决……"——《金融危机》

- **广告本体**：保持口语人设不切播音腔；用个人体验背书（"我今年去南极的时候就用了它，你别说，你还真别说"）。
- **出广告**：用与入口**同一个关键词**原路返回，并立刻抛新问题重启悬念：

> "好，我们接着说回这个**资本的流动**。接下来资本往哪儿流呢？"

- 或复述锚点帮观众接回："好，我们说回美联储啊，刚才呢我们说到了……"
