# 结构模板 · 双层悬念 · 长视频留存 · 情绪曲线

> Step 2（结构选型）和 Step 3（悬念地图）的完整参考。

## 一、五种结构模板详解

通用骨架（所有模板共享）：**钩子 → 扫盲（明示可跳过）→ 机制层层深挖 → 转折/阴暗面 → 统摄模型 → 个人观点升华 → 收尾**。

扫盲段要明示可跳过（"如果你知道它是什么意思哈，可以跳过这一部分"）——尊重不同水平观众，反而留住高阶观众。

### ① 洋葱式（概念扫盲型：做空/通胀/期权）
概念 → 风险 → 高阶玩法 → 更高阶玩法，每层用"咱们接着深挖一层"衔接。
- 独门技巧：**拿进度条当钩子**——"一般人讲做空到这儿就为止了，你看看咱们的进度条，才刚到那儿呢，有趣的地方才刚刚开始。"
- 每层配一个"看似赢家实则翻车"的案例，情绪循环："哇好厉害 → 啊翻车了 → 原来还有更狠的"。

### ② 连续剧式（连环事件型：危机/风波/大战）
每个事件既是独立故事又是下一场的原因。要点：
- 设计一个**口令句当主线扣子**，反复出现（"哎，资本又要开始流动了"）。
- 事件规模递增（墨西哥→泰国→韩国→俄罗斯→烧到美国），每次收尾埋"还没完"。
- 反派登场给"人物志插叙"（讲到一半刹车："我们先放下这边，咱先来了解一下索罗斯他的策略"）。
- 可用战争语汇系统贯穿：主力部队/进攻号角/大决战/缴械投降/保卫战。
- 爽感高潮后急转沉重（反杀之后立刻接"两百万人失业"）——战争片收成纪录片，情绪才有纵深。

### ③ 光暗交替式（符号解剖型：城市/公司/行业）
成功机制与阴暗面轮流出现（机制A → 机制B → 阴暗面1 → 机制C → 阴暗面2 → 模型）。
- 避免成功学单调，也兑现开头"阴暗面"的承诺。
- 阴暗面段落情绪收敛、用词克制（引号式讽刺："每年上千名劳工，叫**自然死亡**"）。

### ④ 案件三明治（灰色题材型：洗钱/骗局/黑产）
开头案件挂起 → 中间手法大赏（由简到繁、由古到今的难度爬梯）→ 结尾用学到的知识回看案件。
- 每种手法配一个真实案例，案例必带"翻车点"（怎么露馅的）——猎奇与警示教育闭环。
- 结尾回看的固定句式："你可能就会觉得不过如此"——给观众"我已经懂行了"的获得感。
- 合规红线即取舍红线："为了不让它成为教学视频，具体操作咱点到为止。"

### ⑤ 总纲变量式（盘点综述型：年度/行业全景）
先立一个总纲变量（如"转向"：37个央行27个降息），每个对象是同一变量的不同取值（美国=降晚了、日本=反向加息、中国=另一种转向）——对象不是并列的，是同一变量的取值，所以不散。
- 章节切换用标准化仪式句："好 + 上章一句话收尾 + 咱们来看看X"。
- 结尾用**总寓言**把所有对象重新缝合（"全球经济=一场赛车：美国急刹车还往前冲、日本打不着火刚点着、德国熄火的老爷车还内讧"）。

## 二、双层悬念系统

### 大悬念（主线钓竿）：1-2个，跨越30%-80%篇幅
- **前置压轴预告**：开头只预告+情绪背书，70%处才兑现——"马斯克搞了一个史无前例的玩法，我当时发现的时候非常震惊。"
- **显式挂起**："这钱怎么洗的，我们一会再聊"（80%处兑现）。
- **二次拆解**：讲完故事宣布"我其实刻意忽略了一个非常重要的核心逻辑"——把一个故事拆成两次消费。
- 自己点破藏点也是彩蛋："你看咱这种点都藏在后面。嘿嘿嘿。"

### 小设问（心跳）：每300-500字一个 ≈ 每40-60秒重启一次注意力
形式轮换使用，不要只用一种：
- 标准自问自答："那利润发动机是什么呢？"
- 替观众提问："你可能要问了……哎，问到顶儿上了哈。"
- 让观众抢答："我估计你猜都能猜出来了，就是AI。"
- 先排除错误答案再揭晓："是为了凑字数吗？哎，那肯定不是。"
- 报幕式揭晓（揭晓前停顿点名）："是谁发出的信号呢？哎，一个熟悉的名字，高盛。"
- 弹幕互动式："大家可以想到谁，打在公屏上。"
- **揭晓信号词**："哎/诶 + 对了/没错"——给观众"答案要来了"的听觉信号。

### 悬念的售后服务
- 容错式安抚（防弃看）："这块逻辑你要是万一没跟上，没事哈，之后都是如出一辙，我们会慢慢再详细讲。"
- 战略性不讲 = 下期钩子："这里头学问还是挺大的，今天就不细说了哈，咱不能一口气吃成个胖子。"省略标准：数理门槛高、与普通人无关、或支线。
- 跨期埋钩："它跟XX的关系，我们有机会再聊。"

## 三、长视频留存系统（20分钟以上必用）

1. **章节切换仪式**："好 + 一句话收尾 + 咱们来看看X"——把40分钟心理上切成7个6分钟，每次给"完成感 + 新开始感"。
2. **每章开头必置反差钩**："日本数据上几乎没有增长，但实际经济在好转——此话怎讲呢？"
3. **中场小故事**：把宏观数据变成一栋楼、一个人的故事（一栋写字楼的违约案代替CMBS数据）。
4. **幽默炸点**均匀分布在各章中后段，不集中在开头。
5. **观众情绪预判**：替观众吐槽套路，再证明自己不是套路——"我估计很多朋友一听人口问题都有点应激了……我跟你说，这个确实有它的特殊性。"
6. **后程节奏换挡**：约2/3处切快览模式，单元篇幅骤降（3000字→300字），用信息加速对抗疲劳。
7. **彩蛋冷知识**放倒数第二章当完播助推器（"大家一定要记住这个国家，圭亚那"）。
8. **终章寓言奖励**：统摄模型只有看到最后才能获得——给完播观众"全懂了"的回报。
9. **横向串线金句**制造上帝视角快感："你发现没有，好像所有经济体都是四季度开始出现变化。"

## 四、情绪曲线与转折词

### 标准情绪走势
**好奇 → 赞叹先行（建立公允）→ 幽默/讽刺加码 → 震惊爆点（放结尾前）→ 沉重纵深 → 温和落地**

三条原则：
1. **批判前先给足正面**：先"真的不得不感叹牛！"再开始讽刺——先赞后损才显公允，直接开黑显得带节奏。
2. **爽感高潮后转沉重**：高潮不是终点，接一段代价与纵深，内容才有分量。
3. **敏感话题主动收敛情绪**：少开玩笑、"咱主要看事、看逻辑"——情绪管理即内容安全。

### 转折词分工表

| 转折词 | 功能 | 示例 |
|---|---|---|
| "结果" | 剧情反转专用 | "本来以为春天降息，结果耗到立秋了还没降" |
| "不过" | 温和转向 | "不过2024年，这个情况终于看到了转变" |
| "但是/但" | 亮出真相 | "数据很好看，但很多人的体感是反过来的" |
| "但有意思的来了" | 预告式转折钩 | "但有意思的来了，后来它换思路了" |
| "哎，别急 / 但你等一下 / 但你仔细看好了" | 暂停-回放-放大细节（侦探式） | "但你仔细看好了，它的要求里边还有第二条" |

转折几乎全用口语惊叹词引导，不用书面的"然而""与此同时"。
